# Flappy Bird Clone (Unity)

A recreation of the classic **Flappy Bird** game developed in **Unity**. This was my **first Unity project**, originally created on **26 May 2024**, and later cleaned up and documented as part of my game development portfolio.

The project focuses on learning the fundamentals of Unity game development, including physics, collision detection, obstacle spawning, UI management, scoring systems, and game state handling.

> **Note**
> This repository contains only the C# scripts and screenshots. The complete Unity project and assets are not included.

---

## 🎮 Features

- Classic Flappy Bird gameplay
- Smooth bird movement using Unity Physics
- Random obstacle spawning
- Score tracking
- Collision detection
- Game Over system
- Restart gameplay
- Simple UI
- Lightweight and beginner-friendly code

---

## 🛠️ Built With

- Unity
- C#
- Unity 2D Physics
- TextMesh Pro
